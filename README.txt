CAS Flashcards (Offline Web App)

1) Unzip this folder.
2) Recommended: run a local web server (required by most phones for localStorage/service worker).
   - On a computer with Python installed:
       python -m http.server 8000
   - Then open: http://<your-computer-ip>:8000
   - On the same Wi‑Fi, open that URL on your phone.
3) Tap 'Add to Home Screen' in your mobile browser to install it like an app.

Data storage:
- Progress, tags, and notes are stored locally in your browser (localStorage).
- Use Export/Import to back up or transfer to another device.

Spaced repetition:
- Due mode shows cards that are due plus up to N new cards/day (Settings).
- Correct schedules the card out further; Incorrect brings it back soon (minutes).
